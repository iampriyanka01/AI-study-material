#instructions.md
'''
Ensure Python 3.11 or newer is installed on your system. 
You can verify this by running `python --version` (or `python3 --version`) in your terminal or command prompt.
From your project directory, create a virtual environment by running:
python -m venv venv

Activate the virtual environment. On Windows, run:
'venv\Scripts\activate


Once activated, it is recommended to upgrade pip:
python.exe -m pip install --upgrade pip

Install the required library:
pip install dotenv
pip install google-genai
or
pip install -r requirements.txt


To verify the installation, you can run:
`pip show google-genai`
or open a Python shell and import the library:
`import google.genai`

To deactivate the virtual environment:
'deactivate'

'''
